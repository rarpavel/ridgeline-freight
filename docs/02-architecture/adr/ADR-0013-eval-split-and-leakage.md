# ADR-0013: Eval dataset: paraphrase, distractors, dev/test split

Status: Accepted · Date: 2026-11-02

## Context
Questions generated from the same registry as the documents are lexically identical to document sentences, and tuning on the reported set inflates numbers.

## Decision
Questions are generated by a different model than the document writer, must paraphrase (no reuse of `statement` wording), include distractor entities for comparisons, and are manually reviewed. 40 questions in five categories, split dev 12 / test 28, stored on each question. Thresholds and prompts are tuned on dev; README reports test only.

## Consequences
- Honest, defensible numbers; slightly lower headline figures.
- A dedicated `injection` category and a CI regression gate are roadmap items.
